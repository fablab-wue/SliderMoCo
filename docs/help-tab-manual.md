# Help tab copy

The phone **🕮** tab is a short on-device reminder. The full book is the Markdown set in `docs/` on the PC (not served from the Pico unless you copy it into `www/`).

This chapter is the copy that belongs on that tab, plus what we put in `index.html`.

---

## On-device Help (shipped)

- SliderMoCo is a WLAN / USB remote for **one** SliderMC.
- **ENABLE** (Home) must be on. Grey = driver error.
- **MOVE:** tap ≤ ⅓ s = cruise; hold longer = run while held. Same direction again or **⏹** stops cruise.
- **⏹** tap = `MS`. Hold 1 s = halt (`H`). Hold 2 s = disable (`SE 0`).
- SPEED is commanded `SS`. Footer **Spd** is actual.
- Soft window: **Window** tab. Marks: **AB**. Interval shooting: **Timelapse** (survives phone sleep). Timeline Play is **desktop only** and does **not** survive sleep.
- Full manuals: repo `docs/user-manual.md` (architecture + index).

---

## What Help is not

It is not the Timeline chapter, not a wiring diagram, and not a substitute for [Safety](safety-manual.md). Keep the tab short so it fits a phone without scroll fatigue.
